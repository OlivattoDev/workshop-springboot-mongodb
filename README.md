# Projeto com MongoDB e Spring Boot

## Sobre o projeto

Este projeto consiste em uma aplicação backend construída durante as aulas de programação Java, no qual tem o objetivo de implementar operações CRUD, realizar consultas com Sprig Data e MongoRepository e implementar associações entre objetos.

# Tecnologias utilizadas
## Back end
- Java
- Spring Boot
- Maven
- Postman
- MongoDB
- NoSQL

# Como executar o projeto

## Back end
Pré-requisitos: Java 11

```bash
# clonar repositório
git clone https://github.com/OlivattoDev/workshop-springboot-mongodb

# entrar na pasta do projeto back end
cd workshop-springboot-mongodb

# executar o projeto
./mvnw spring-boot:run
```
